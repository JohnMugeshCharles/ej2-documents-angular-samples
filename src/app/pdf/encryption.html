Click the button below to view a PDF created with JavaScript PDF Library. Please note that Adobe Reader or its equivalent is required to view the resultant document.

Encryption Settings

This sample demonstrates how to encrypt the PDF document with encryption standards like 40-bit RC4, 128-bit RC4, 128-bit AES, 256-bit AES Revision 6 (PDF 1.7 Extension Level 3) and advanced encryption standard 256-bit AES Revision 6 (PDF 2.0) to protect documents against unauthorized access.

It is possible to protect with user password or owner password or both passwords and also possible to change or remove password and permission. More information about JavaScript PDF Library can be found in this documentation section.
