This sample demonstrates how to customize the primary toolbar in the PDF Viewer by selecting a specific set of visible items and creating your own custom buttons mapped to viewer APIs.

This sample shows a PDF Viewer with a configurable primary toolbar. Use the checkbox drop-down to choose which toolbar items should be shown, then click Customize to apply the selection.

You can also add a custom toolbar item: pick Add Text Button to configure a styled label inside the popup, or Select Icon Button to pick from a scrollable icon grid. Then choose an API Action such as Lock PDF, Flatten PDF, or Add Watermark, and click ADD BUTTON to attach it to the viewer toolbar.

Available toolbar items in this sample are Open, Page Navigation, Magnification, Edit Annotation, Text Search, Print, and Download.

More information on the PDF Viewer toolbar customization can be found in this documentation section.
