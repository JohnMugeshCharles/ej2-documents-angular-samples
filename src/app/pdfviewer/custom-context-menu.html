Add Custom option at bottom

This customization empowers users to add new context menus on PDF pages, annotations, and form fields. In this sample:

  • Selecting text on pages reveals custom context-menu options that let users search for the selected text on Google or add a rectangle annotation around the selection.
  • Annotations can be locked or unlocked directly from the context menu.
  • Form fields can be made read-only or editable directly from the context menu.
  • When custom options are positioned at the bottom, the category selectors let users choose which annotation, text-selection, and form-field actions are included.
  • Customization is achieved using the following APIs:
    • Customize the context menu by selectively displaying custom options and hiding existing menu items using the boolean parameters of the addCustomMenu() method.
    • Position custom menu items above or below existing items using the final boolean parameter of the addCustomMenu() method.
    • Tailor the visibility of custom menu items using the customContextMenuBeforeOpen event.
    • Implement custom actions using the customContextMenuSelect event.
