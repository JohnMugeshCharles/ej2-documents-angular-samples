This sample demonstrates the programmatic PDF navigation features of the PDF Viewer. Bookmarks are extracted from the PDF and displayed in a custom side panel to enable direct navigation. The sample also showcases programmatic text search with automatic page navigation, programmatic zoom in/out, and enabling text interactions.

The PDF Viewer component provides comprehensive programmatic navigation capabilities with custom toolbar implementation. This sample demonstrates:

  • Programmatically retrieving bookmarks from the PDF document - viewer.bookmark.getBookmarks()
  • Displaying bookmarks in a custom-created side panel
  • Programmatically navigating to the respective bookmark destination on click - viewer.bookmark.goToBookmark(pageIndex, y)
  • Go to First Page - viewer.navigation.goToFirstPage()
  • Go to Previous Page - viewer.navigation.goToPreviousPage()
  • Go to Next Page - viewer.navigation.goToNextPage()
  • Go to Last Page - viewer.navigation.goToLastPage()
  • Go to Page - viewer.navigation.goToPage(pageIndex)
  • Programmatically searching text within the PDF document - viewer.textSearch.searchText(searchText, isMatchCase)
  • Search Next - viewer.textSearch.searchNext()
  • Search Previous - viewer.textSearch.searchPrevious()
  • Cancel Search Text - viewer.textSearch.cancelTextSearch()
  • Zoom In - viewer.magnification.zoomIn()
  • Zoom Out - viewer.magnification.zoomOut()
  • Fit To Page - viewer.magnification.fitToPage()
  • Text Selection - viewer.interactionMode = 'TextSelection'
  • Pan Mode - viewer.interactionMode = 'Pan'

More information on the PDF Viewer programmable navigation capabilities can be found in this documentation section .
